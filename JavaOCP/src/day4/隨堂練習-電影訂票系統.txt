🎬 電影訂票系統（企業級物件設計）
任務要求顧客可以用 "A1x2, B3, C2x3" 格式訂票（x數量，沒寫x預設1張）
意義：A廳1排2張、B廳3排1張、C廳2排3張

Movie-Hall-Seat 三層物件關係
Movie("復仇者聯盟4") ──┐
                    ├── Hall("A", "A廳") ──┐
                    │                      ├── Seat(A廳, 1排, $250)  ← "A1"
                    │                      └── Seat(A廳, 2排, $240)  ← "A2"
                    │
                    └── Hall("B", "B廳") ──┐
                                          └── Seat(B廳, 3排, $220)  ← "B3"

Movie("陽光女子合唱團") ───┐
                   └── Hall("C", "C廳") ──┐
                                          └── Seat(C廳, 2排, $260)  ← "C2"

主程式解析邏輯
輸入格式：
"A1" → 復仇者聯盟4 A廳1排，1張

"A1x2" → 復仇者聯盟4 A廳1排，2張

"B3x2,C2x1,A1" → 復仇者聯盟4 B廳3排2張、沙丘2 C廳2排1張、復仇者聯盟4 A廳1排1張

解析步驟：
1. split(",") → ["B3x2", "C2x1", "A1"]
2. 每個項目：
   - 有 "x" → split("x") → ["B3", "2"] → B3×2張
   - 有 "x" → split("x") → ["C2", "1"] → C2×1張
   - 沒 "x" → 直接用 → A1×1張
3. findByCode() → 自動取得 Movie → Hall → Seat 完整資訊
